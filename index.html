핵심 기능

🎨

서버별 컬러 자동 적용

서버를 선택하면 천족·마족에 맞는 컬러로 전체 테이블이 자동으로 바뀝니다.

🧭

서버 그룹 자동 세팅

내 서버의 그룹을 고르면 어비스 아티팩트 점령전과 필드보스 시간이 그룹에 맞게 즉시 정렬됩니다.

🔔

시작 전 음성 알림

알림을 켜 두면 컨텐츠가 시작되기 전에 음성으로 알려 줍니다. 게임에 집중하세요.

⏳

남은 시간 · 하이라이트

다음 컨텐츠까지 남은 시간을 보여 주고, 진행 중이거나 곧 시작하는 컨텐츠는 하이라이트로 표시합니다.

🧱

아그로 젠 타임 직접 입력

남은 시간을 입력하면 12시간 주기로 타임테이블에 바로 반영됩니다.

🪟

창 크기 · 위치 기억

원하는 크기로 조절하면 다음 실행 때 같은 위치와 설정으로 열립니다.

📌

게임 위 mini 알림창

다가오는 주요 컨텐츠를 게임 화면 위에 작게 띄웁니다. 위치·크기·투명도를 조절할 수 있습니다.

🔄

업데이트

새 버전이 나오면 NEW UPDATE 표시가 뜹니다. 눌러서 확인만 하면 자동으로 설치되고 다시 실행돼요.

🔒

게임과 독립

게임 클라이언트와 통신하거나 게임 데이터를 읽지 않는, 시간표 계산 전용 프로그램입니다.

시작하기

설치부터 사용까지 3단계

다운로드 · 설치

위의 다운로드 버튼으로 설치 파일을 받아 실행하세요. 설치 위치를 고를 수 있습니다.

서버 · 그룹 선택

[서버 설정]에서 내 서버를 고르고 그룹을 맞추면 시간표가 즉시 내 서버 기준으로 바뀝니다.

알림 켜기

음성 알림을 켜고, 필요하면 mini 버튼으로 게임 위 알림창을 띄워 두세요.

내 그룹 확인 방법 · 게임사 공지(CM아지트)에서 내 서버의 매칭 그룹을 확인한 뒤, 그룹 편성표(인벤 소개글)에서 내가 속한 그룹을 찾으세요.
처음 실행할 때 Windows가 “PC를 보호했습니다” 화면을 보여 줄 수 있어요. 추가 정보 → 실행을 누르면 계속 진행됩니다. (개인이 만든 무료 프로그램이라 코드 서명이 없습니다.)

자주 묻는 질문

 

무료인가요?

네, 무료입니다. 광고도 없습니다.

게임에 영향을 주거나 계정에 문제가 생기지 않나요?

이 프로그램은 게임을 조작하거나 게임 데이터를 읽지 않고, 정해진 일정을 계산해서 보여 주는 시간표입니다. 다만 엔씨소프트와 무관한 비공식 팬 프로그램이며, 사용에 대한 책임은 사용자에게 있습니다.

업데이트는 어떻게 하나요?

새 버전이 있으면 프로그램 상단 버전 옆에 NEW UPDATE가 표시됩니다. 눌러서 확인하면 자동으로 받아 설치하고 다시 실행됩니다. 처음 버전(1.0.0)을 쓰고 계시다면 이 페이지에서 최신 설치 파일을 한 번만 직접 설치해 주세요.

설정이나 입력한 값은 어디에 저장되나요?

내 PC에만 저장됩니다. 서버 선택, 창 위치, 아그로 기준 시각 등은 외부로 전송되지 않습니다.

게임 위 mini 알림창이 안 보여요.

게임을 “창모드” 또는 “전체 창모드”로 실행해 주세요. 전용 전체화면에서는 다른 창이 가려질 수 있습니다. 잠금 해제는 자물쇠를 Alt + 클릭하거나 Ctrl + Alt + L 입니다.
